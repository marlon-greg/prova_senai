# Programação Back-End — dados comuns para os agentes

Matéria (EXATA): "Programação Back-End" (2º semestre do técnico, alunos de 15 a 18 anos). O plano de curso não fixa a
linguagem: os bancos já existentes usam **JavaScript/Node.js com Express** (e SQL/MySQL para persistência) — siga isso.
Classes em JavaScript (class, constructor, extends, get/set, #privado), módulos (import/export), npm.
Questões com código: mostre o trecho pronto entre crases e pergunte o que faz, o que imprime, o que está errado, qual a
diferença — dissertativa NUNCA pede para escrever código (código é cobrado na prática).
Capacidades: back.ct1 POO; back.ct2 diagramas de classe; back.ct3 código limpo; back.ct4 características do back-end web;
back.ct5 ambiente; back.ct6 entrada, processamento e saída; back.ct7 design patterns; back.ct8 frameworks; back.ct9 base de
dados; back.ct10 transferência de arquivos; back.ct11 notificações cliente/servidor; back.ct12 API/web services;
back.ct13 regras de negócio; back.ct14 publicação.
Banco para não repetir (--contra): bancos/gerados/banco_back.json. Arquivo em bancos/gerados/back/.
